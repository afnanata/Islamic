# المستشفى الإسلامي – عمّان | تصميم الموقع الجديد

موقع ثابت (HTML / CSS / JavaScript) باللغة العربية، يعمل دون أي أداة بناء أو خادم.

## الصفحات

| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية |
| `about.html` | من نحن (`#story` · `#vision` · `#doctors`) |
| `news.html` | الأخبار |
| `departments.html` | الأقسام الطبية – بحث وتصنيف (`?q=` للبحث المباشر) |
| `department.html?id=er` | صفحة قسم واحد حسب المعرّف |
| `gallery.html` | معرض الصور مع عارض كامل الشاشة |
| `careers.html` | الوظائف ونموذج التقديم |
| `contact.html` | إتصل بنا |
| `admin.html` | لوحة التحكم (`#news` · `#depts` · `#docs` · `#gal` · `#inbox`) |

## الملفات المشتركة

```
assets/css/style.css   التنسيقات لكل الصفحات
assets/js/data.js      المحتوى (الأقسام، الأطباء، الأخبار، الصور) وحفظه
assets/js/site.js      القوائم الكبيرة، البحث، معرض الصور، النماذج
assets/js/admin.js     لوحة التحكم
```

الصور مرتبطة مباشرة من الموقع الحالي `islamic-hospital.org`.

## التشغيل محلياً

افتح `index.html` في المتصفح، أو شغّل خادماً بسيطاً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر على GitHub Pages

Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.

## ملاحظة عن لوحة التحكم

لوحة التحكم نسخة تجريبية: التعديلات والرسائل تُحفظ في متصفح المستخدم (localStorage) فقط، ولا يوجد تسجيل دخول.
للتشغيل الفعلي يجب ربطها بقاعدة بيانات وخادم ونظام صلاحيات. يمكن نقل المحتوى بين الأجهزة عبر «تصدير البيانات» و«استيراد البيانات».
